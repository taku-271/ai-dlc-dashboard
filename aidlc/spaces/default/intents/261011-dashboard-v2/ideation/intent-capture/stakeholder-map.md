# ステークホルダーマップ（v2）

## 主要ステークホルダー

| ステークホルダー | 関心事 | 役割 |
|------------------|--------|------|
| 依頼者（開発者本人） | 承認のたびに読む量を減らしたい。ただし見る範囲を AI だけに決めさせたくない | 意思決定者・利用者・承認者 |
| 将来のチームメンバー | 誰がどこまで確認して承認したかを後から辿りたい | 将来の利用者 |
| AI-DLC エンジン | 状態ファイルと audit を壊されないこと。承認は会話経由で記録されること | 読み取られる側 |

## 意思決定者と影響者

- 意思決定者: 依頼者本人
- 影響者: 将来のチームメンバー（確認範囲の記録形式に影響）

## コミュニケーション

- 各ステージの承認ゲートで止まり、Claude Code の会話内で確認する
- 説明・成果物とも日本語
