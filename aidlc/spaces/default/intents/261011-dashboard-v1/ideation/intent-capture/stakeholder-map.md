# ステークホルダーマップ

## 主要ステークホルダー

| ステークホルダー | 関心事 | 役割 |
|------------------|--------|------|
| 依頼者（開発者本人） | 判断待ちの Intent をすぐに見つけたい。確認する範囲を AI だけに決めさせたくない | 意思決定者・利用者・承認者 |
| 将来のチームメンバー | 自分が担当する Intent の判断待ちを知りたい | 将来の利用者（v3 以降） |
| 将来の管理者 | チーム全体の Intent の進み具合と滞留を見たい | 将来の利用者（v3 以降） |
| AI-DLC エンジン | 状態ファイルと audit を壊されないこと | 読み取られる側（ダッシュボードからは変更しない） |

## 意思決定者と影響者

- 意思決定者: 依頼者本人。すべての承認ゲートで判断する
- 影響者: 将来のチームメンバーと管理者。v1 の設計（担当者フィールド、データ取得層の分離）に要望として反映するが、v1 の判断には参加しない

## コミュニケーション

- 進め方: 各ステージの承認ゲートで止まり、Claude Code の会話内で確認する
- 区切り: 調査結果と実装計画の提示時、v1 の実データ確認時に必ず止まる
- 言語: 説明・成果物とも日本語
