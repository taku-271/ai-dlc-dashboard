## 質問の前に：優先度の叩き台

ここまでの決定をもとに、機能の候補を優先度（MoSCoW）で仮に分けました。
**Must**＝MVPに必須／**Should**＝重要だが回避策がある／**Could**＝余裕があれば／**Won't**＝今回はやらない

### Must（叩き台）

| ID | 機能 | 出典 |
|----|------|------|
| M-1 | 設定ファイルで監視対象のプロジェクトを指定する（複数件を書ける書式。最初は1件でもよい） | intent-capture Q8、要件変更その2 |
| M-2 | AI-DLC のファイルを読み取る（v2 の構成。多少の書式の違いに寛容。読めない部分は警告して続け、1プロジェクトの失敗を他に波及させない） | 制約 C-5・C-9 |
| M-3 | 承認待ち一覧（`[?]`）：全プロジェクト横断・最上部・どのプロジェクト／Space／Intent か分かる・承認待ちになった日時（取れる場合） | intent-statement §5 |
| M-4 | 修正中一覧（`[R]`） | intent-statement §5 |
| M-5 | Intent 一覧：現在ステージ・進捗・最終更新日時。「プロジェクト → Space → Intent → ステージ」の階層 | intent-statement §5 |
| M-6 | 127.0.0.1 だけで待ち受けるローカルの Web サーバーと、ブラウザの画面 | 制約 C-2 |
| M-7 | 画面をリロードせずに自動で反映する | 要件変更その1 |
| M-8 | タブタイトルに承認待ちの件数（全プロジェクトの合計）を出す | intent-capture Q7 |
| M-9 | フックによる変更の合図と、合図を受けたプロジェクトの読み直し（フックはユーザー全体の設定に置く） | feasibility Q8〜Q10、制約 C-7・C-10 |
| M-10 | 起動時に全プロジェクトを読む | feasibility RAID RK-3 |
| M-11 | 「対象なし」の表示と、壊れたファイル・読めないプロジェクトの警告表示 | 受け入れ基準、制約 C-5 |
| M-12 | テスト用データ（承認待ち・修正中・完了が混ざった複数 Intent）を使った自動テスト | 受け入れ基準 |

### 判断が必要なもの（下の Q2〜Q6 で決めます）

「回答待ち」の検出、「入力待ち」の表示、Linux・Windows の確認方法、Claude Code の外で起きた変更の補完、フックの登録方法、承認待ちの経過時間の表示

### Won't（今回はやらない・叩き台）

ルール数の推移、セッションコストの表示、ファビコンのバッジとデスクトップ通知、自動起動・常駐、監査ログからの「承認待ちの可能性」の推定、旧形式（`aidlc-docs/`）の読み取り、ダッシュボードからの承認操作、Slack などへの通知。
Host ヘッダー確認は、仕事の案件を監視対象に加える**前に**追加する条件付き項目とします（制約 C-11）。

### 既に決まっていること（質問しません）

- **進める順序**：組織のルール（org.md の Walking Skeleton）により、新規開発の mvp では、最初に全体を薄く1本通す「ウォーキングスケルトン」を作り、承認を得てから残りを進めます。
- **期限**：全体で1〜2週間以内（feasibility Q7）。特定の機能だけの期限はありません。

## Q8. 期間と Must の量 — 1週間では厳しい見込みです。どう進めますか？（範囲と期間の検証による追加質問）

| 項目 | 見積もり |
|---|---|
| 使える時間 | 1日30分〜1時間 × 7〜14日 ＝ 約3.5〜14時間（Q7-B） |
| 残り16ステージの質問・レビュー・承認 | 1ステージ20〜30分として約5〜8時間（実装後の動作確認は別） |
| Must の数 | 16件（叩き台12件＋回答待ち・入力待ち・再読み込みボタン・経過時間） |

2週間なら収まる見込みですが、1週間では厳しく、Must の比率も高い（Should はほぼ Linux・Windows の確認だけ）ため、余裕がありません。

- A. 目標を「2週間」に置き、ウォーキングスケルトンの完成時点で残りの範囲を見直す
- B. 1週間を目指し、「入力待ち」の表示（誤表示の対策が必要で不確実性が高い）を Should に下げる
- C. 期限を延ばす（範囲を優先）
- D. このまま（1〜2週間・Must 16件）で進める
- X. Other (please specify)

[Answer]: D
